# Czech description

**Co z toho plyne pro AI?**

Závěrečný syntetizující modul. Rozlišuje objevování vzorů, predikci, generování hypotéz, testování hypotéz, kauzální inferenci a generalizaci. Schopnost nacházet vzory není totéž co schopnost určit, které vzory jsou skutečné. Cílem není tvrdit, že „AI je špatná“: prohledávat data je její práce. Chyba nastává, když je vzor nalezený rozsáhlým hledáním prezentován jako nezávisle potvrzený důkaz.

# English description

**What Does This Mean for AI?**

The closing synthesis module. It separates pattern discovery, prediction, hypothesis generation, hypothesis testing, causal inference and generalization. The ability to find patterns is not the same as the ability to establish which patterns are real. The point is not that "AI is bad": searching for patterns is its job. The error is presenting a pattern found by extensive search as independently confirmed evidence.

Main concepts: pattern discovery, hypothesis generation, generalization, causal inference, independent replication
